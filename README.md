# Supply‑Chain Transition Feasibility Scoring Model
Portfolio project: Multi‑criteria scoring model for firm supply‑chain transition feasibility with bottleneck diagnosis. Built in R / RStudio.

## Project structure
- `scripts/`: all analysis R scripts, sequential numbered
- `data/`: raw input data (not tracked by git)
- `output/`: cleaned datasets and result tables (csv output)
- `figures/`: exported plots for documentation

> Raw source data is excluded from GitHub for data privacy.
